Per step, models are used to predict the entire remaining day.
Forecasts are passed to the MPC Controller

This already beats hist avg. persist, but it has the main drawback of cumulative rollout errors.

So we compare 3 different architecture variants:

- single step recursive forecasting
- multi step forecasting with interpolation (single model for multiple horizons, where the horizon is included in the features)
- multi model forecasting with interpolation (1 model per horizon)
