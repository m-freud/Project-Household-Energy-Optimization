
For load profiles, we use this residential dataset from Switzerland:
https://zenodo.org/records/21398769?preview_file=dataset.zip
The downloaded files are expected in `data/dataset_CH_load/`: household
measurements under `smart_meter_data/` and the household metadata in
`metadata.csv`.

### Filtering and staging

`data/dataset_CH_load/filter_single_family_houses.py` keeps only households
whose installation type is `Single-family house`, which have at least 70,000
data points, and for which all of these metadata flags are false:
`1_ewh`, `1_hp`, `1_hp-add`, `1_hp-wh`, `1_ev`, `1_storage_heating`,
`1_direct_heating`, and `1_change`. It writes the selected metadata to
`metadata_filtered.csv` and copies the corresponding meter files to
`smart_meter_data_filtered/`.

`data/dataset_CH_load/create_ch_database.py` reads each filtered CSV's
`kWh_to_installation` column and combines the households into the wide
`load` table in `sqlite/staging/CH_loads.db`. It removes the timezone
information from timestamps, derives `period` 1-96 from the 15-minute
timestamp, and outer-joins households by timestamp and period. A missing
measurement therefore remains null. The CSV values are energy per
15-minute interval in kWh; multiplying each by four converts them to average
power in kW for that interval.

`data/dataset_CH_load/create_metadata_table.py` calculates daily statistics
for each household. It only records complete household-days with 96
non-null values. `total_energy` is the sum of the 96 kW values multiplied by
0.25 hours (kWh); `max_load` is the day's peak power (kW). Other statistics
are also stored, but are not used by the active load selection below.

`data/dataset_CH_load/create_valid_pool_table.py` compares those daily
`total_energy` and `max_load` values with `base_load_metadata` in
`sqlite/source_original.db`. A CH household-day enters
`CH_loads.db.base_load_pool` only when both values are within the inclusive
minimum-to-maximum range of the original profiles. The original database's
metadata is therefore a prerequisite for building this pool.

### Runtime selection

`data/dataset_CH_load/select_ext_runtime_profiles.py` selects from
`base_load_pool` and writes `(init_cp, household_id, date)` rows to
`CH_loads.db.runtime_pool_by_cp`. The target counts follow the original
`initial_cp` distribution: 152 profiles at 3.45 kW, 80 at 6.90 kW, and 18
at 10.35 kW. A candidate's `max_load` must also be in the band for its
target: `(2.30, 3.45]`, `(3.45, 6.90]`, or `(6.90, 10.35]` kW,
respectively.

The selection deliberately spreads the 250 days across 40 distinct CH
households. It first chooses the highest-CP profiles from households with
many eligible days, then chooses additional households based on candidate
availability and allocates the remaining medium- and low-CP profiles across
them. Per-household quotas are six or seven days. The script uses
`random.Random(42)` when choosing days. In
`src/ingestion/create_replacement_db.py`, each target household's original
`initial_cp` determines which CP group to draw from; its selected CH
household-day is copied as 96 values into that target's `base_load` column.
No further scaling is applied.

### Training selection

`src/ingestion/create_training_tables.py` builds the training `load` table
from the full wide CH `load` table. It excludes every CH household ID found
in `runtime_pool_by_cp`, not just the particular runtime days. The remaining
households' full time series are retained in
`sqlite/source_runtime_training.db`; this is not a day-level sample and no
additional load scaling is applied. With the current data, the split is 40
runtime source households and 41 training household series.

`data/dataset_CH_load/create_stratified_samples.py` is a separate,
distribution-matched alternative: it samples 250 days using 2D quantile bins
of the original `max_load` and `total_energy` distributions and labels the
remaining household IDs as training data. It writes
`base_load_runtime_profiles` and `base_load_training_profiles` in
`CH_loads.db`; these tables are not consumed by the active runtime and
training builders described above.
