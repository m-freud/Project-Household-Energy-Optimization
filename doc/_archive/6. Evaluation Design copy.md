# 6. Evaluation Design

We perform a set of runs where each run is defined by:
- households
- controller
- scenario

For each run, we calculate forecasting errors, net cost,
and target misses.

How do we handle target misses?
Controller has to hit 95% of targets, for each target.
We only compare costs for runs where both controllers hit their targets.

How do we quantify forecasting errors?
- avg rsme
- avg 1st step rsme
- rsme over full horizon based on current timestep (2D)

Net cost is easier
