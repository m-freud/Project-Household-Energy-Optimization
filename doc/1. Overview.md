# 1. Overview

This is an exploration of control strategies for Home Energy Management Systems (HEMS).

We simulate a set of 250 virtual households to compare different control strategies.

This involves future-agnostic, rule-based controllers as baselines as well as controllers that rely on predictive machine learning and mathematical models (MPC).

Both MPC and predictive ML are examples of systems implying their own logic so engineers dont have to come
up with all them rules themselves.

Even without user-specific knowledge, we can use ML technologies to greatly improve our decision making.

## Setup and Usage

### Quickstart

Create and activate a virtual environment, then install dependencies from the
repository root:

**Linux / macOS**

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

**Windows PowerShell**

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

Run households 1-20 for both `default_scenario` and `00_baseline`:

```bash
python -m src.simulation.simulation \
  --households 1-24 \
  --scenarios default_scenario,00_baseline \
  --controllers waterfall,mpc_history_avg,mpc_oracle,mpc_single_step,mpc_multi_step,mpc_multi_model
  --run-id demo
```
