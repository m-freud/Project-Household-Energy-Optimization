# 8. Conclusion and Outlook

Preliminary simulations show that MPC with XGBoost forecasts can lower daily net electricity costs compared with MPC using historical averages. In the initial comparison of XGBoost variants, recursive single-step forecasting achieved slightly lower average costs than the multi-horizon approaches tested so far. These comparisons used untuned models. The full benchmark will report costs alongside charging target attainment.

## 8.1 Limitations

- Each household is simulated for one day, which limits what the results say about performance over longer periods.
- Load, PV generation, and EV activity profiles come from separate sources. The simulation therefore cannot test whether correlations between these signals improve forecasts.
- The current setup evaluates forecasts across households. Testing personalized models would require a history of several days for each household.
- PV forecasts currently rely on profile history. Weather forecasts could improve predictions when conditions change during the day.
