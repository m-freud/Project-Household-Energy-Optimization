## 3. Data acquisition and preparation

The original 250-household dataset is stored in a SQLite database and combined with external profiles for load, PV, and EVs.

## 3.1 Original dataset and database structure

### Origin


The project is based on the data from [this paper](https://www.sciencedirect.com/science/article/pii/S2352340923003372?via%3Dihub) from june 2023.

It represents a European residential community of 250 households, including energy consumption from the grid, two electric vehicles (EVs) with usage and availability profiles, photovoltaic generation (PV) for 200 households, and battery storage systems (BESS) for 150 households.

The data covers one 24h-day divided into 96 timesteps of 15 minutes.

Everything is stored in an Excel workbook found in `data/dataset_original/EC_EV_dataset.xlsx`. Table Descriptions can be found in General description.docx


`src/ingestion/table_loading_original.py` reads the relevant 
Excel ranges and writes the source tables to
`sqlite/source_original.db`.

The original database is then copied as `sqlite/source_runtime.db`, where profiles for base load, PV and EVs are replaced with new data.


### Format

The original Excel file contains technical lookup-tables as well as 96-step time series data.

Time series are stored as wide tables, with one `period` column (1-96) and columns `"1"` through `"250"` for the day profiles of each household.
