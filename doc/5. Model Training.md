# 5. Model Training

The XGBoost predictors forecast household base load, PV generation, and the availability status of both EVs. At each simulation step, the forecasts cover the rest of the day and serve as inputs to the MPC controller. The current models are untuned baselines.

We compare three forecasting approaches:

- **Recursive single-step.** A model predicts one step ahead and feeds its own predictions back as inputs to extend the forecast. Errors can accumulate during this rollout.
- **Multi-step with a shared model.** A single model predicts directly at selected horizons, using the horizon as an input feature. Interpolation fills the gaps between those horizons.
- **Multi-step with separate models.** Each selected horizon has its own model. Interpolation fills the gaps between their forecasts.

Historical averaging provides the baseline for assessing forecast accuracy and the effect of forecasts on MPC costs.
